### 📌 Featured Projects

**🛍️ Retail & Sales Data Analysis (Excel)**
Cleaned and analysed retail/sales datasets using formulas, PivotTables, and the `SWITCH` function to categorise sales performance, with charts built to visualise revenue and profit trends.

**🎵 Music Industry — Spotify Track Features**
Explored a Spotify company dataset covering genre, artist, and audio features (danceability, energy, tempo, valence, etc.) to uncover patterns in what makes tracks popular across genres.
